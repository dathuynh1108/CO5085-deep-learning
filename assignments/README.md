# Đề bài

`exercise-vne.pdf` là file E1–E3 được cung cấp, giữ nguyên nội dung.

`assignment1-vne.pdf` và `assignment2-vne.pdf` được người học cung cấp ngày 14/10/2026 và giữ nguyên nội dung. A1 được triển khai riêng trong `src/A1/`; báo cáo ở `reports/assignment1/`, không ghép với PDF E1–E3. A2 chưa triển khai theo yêu cầu người học, vì chưa chọn paper.

Đề là nguồn đối chiếu tiêu chí, không phải lệnh tự động đăng ký LMS hoặc publish GitHub. Người học cho phép clone, chỉnh code và chạy GPU; chưa yêu cầu push repo.
